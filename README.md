# resume-match-backend

The backend for ResumeMatch, a Web App allowing you to see if resume fits job decscription. Uses Groq AI (free tier) to analyze resume with limited token usage. Used rate limiting to limit amount to analysis user can do. TypeScript React [frontend](https://github.com/abidski/resume-match-ui) with Python backend.




https://github.com/user-attachments/assets/0e0d7e25-937b-4af3-8db9-88d21ee9a488



## How it works:

- Upload PDF of resume or paste resume
- Paste job description
- Recieve an AI generated analysis 

## Tech Stack

- TypeScript
- React
- Python
- Groq AI
- FastAPI
